# ***Tarea Proyecto API Rest***

- Este es un proyecto de crear una API rest usando .Net y C# para entender el uso de controladores.

- El programa tiene una conexión a la base de datos utilizando EntityFrameWork. Tenemos 3 tablas las cuales son "Empleados", "Puestos" y "Clientes".

## ***Controladores***

- Después lograremos encontrar todos nuestros controladores los cuales están encargados de la lógica de uso para crear, modificar, buscar y listar cada uno de los datos en nuestra base de datos.
